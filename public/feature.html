Cara Belajar dari Project Ini

1

Clone & Setup

Clone repository dari GitHub, install dependencies dengan npm install, dan setup environment variables untuk Firebase dan Google OAuth credentials.

2

Pelajari Struktur Kode

Pahami struktur folder dan bagaimana komponen React diorganisir. Pelajari file-file utama seperti App.tsx, komponen auth, dan file upload.

3

Pelajari Flow Autentikasi

Trace flow login dari Google Sign-In button, bagaimana token didapatkan, dan cara menyimpan session user menggunakan Firebase Auth.

4

Eksperimen dengan Kode

Modifikasi kode, tambahkan fitur baru, atau ubah styling. Project ini adalah playground untuk belajar React + Google Auth.
